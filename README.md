# CV Studio — מפרויקט לניסיון

מדריך חינמי לשיפור תיאור פרויקט בעזרת סוכן ה-AI האישי שלך, ועמוד מידע על שירות בהכנה.

## התחלה חינמית

1. פתחו את [המדריך לסוכן](PROMPT.md) והעתיקו את ההנחיה לשיחה בסוכן שלכם.
2. צרפו תיאור פרויקט ללא פרטים מזהים או מידע רגיש. השימוש במודל כפוף לחשבון ולתנאים של הספק שלכם.
3. בדקו כל ניסוח מול העבודה שביצעתם. אין כאן אימות חיצוני, ציון ATS או הבטחה לקבלה לעבודה.

המדריך אינו דורש מנוע מקומי, מפתח API שלנו, התקנת תוכנה או פתיחת חשבון אצלנו.

## שירות בהכנה

חבילת ״מפרויקט לניסיון״ מתוכננת לכלול ניסוח בעברית ובאנגלית והכנה לשאלות ראיון על בסיס החומרים שלכם. מחיר הניסוי המוצע הוא 149 ₪ בתשלום חד-פעמי; היקף העבודה והמחיר יאושרו לפני הזמנה. אין במאגר מערכת הזמנות, סליקה או העלאת קבצים.

[בירור זמינות בדוא״ל](mailto:asafa3@gmail.com) — לפנייה ראשונית בלבד, ללא קורות חיים או מסמכים רגישים.

## תוכן המאגר

- `site/index.html`: עמוד המידע; אפשר לפתוח ישירות בדפדפן.
